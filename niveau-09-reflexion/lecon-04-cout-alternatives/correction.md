## E1 — Reproduire les mesures

Ordres de grandeur attendus (voir le cours) : directe et générique ≈ 13,5 µs, réflexion par index
≈ 105 µs, par nom ≈ 680 µs. La boucle écrite dans le corps du benchmark sur la variable globale
`books` donne ≈ 30 µs : le compilateur ne traite pas une boucle sur une variable globale comme sur un
paramètre (il ne peut pas supposer que la slice ne change pas pendant la boucle). `go build -gcflags=-m`
montre aussi que `SumBy` et sa fonction littérale sont *inlinées* dans l'appelant : la version générique
devient, après compilation, la même boucle que la version directe. Le niveau 11 détaille ces analyses.

## E2 — Oublier de régénérer

Le code **compile** (le fichier généré ne parle pas de `ISBN` : il est simplement incomplet). C'est le test
de cohérence qui échoue :

```
colonnes : "id, title, author, price, created_at, isbn" contre "id, title, author, price, created_at"
```

Sans ce test, la colonne `isbn` ne serait jamais lue ni écrite, en silence. La vérification en CI :

```sh
go generate ./... && git diff --exit-code
```

Elle échoue si la génération modifie un fichier versionné, donc si quelqu'un a oublié de régénérer.

## E3 — Le générateur se trompe

Avec `format.Source`, le **générateur** échoue, en montrant le code fautif :

```
code généré invalide : 10:21: expected operand, found ',' (and 1 more errors)
// Code generated by dbgen; DO NOT EDIT.
…
```

Sans lui, le fichier mal formé serait écrit, puis la compilation du paquet échouerait sur un fichier que
personne n'a écrit à la main, avec des numéros de ligne qui ne correspondent à aucun source édité. Un
générateur doit échouer **au plus près de la cause** : c'est lui qui a un bug, pas le paquet.

## E4 — `stringer`

```go
func (s Status) String() string {
	switch s {
	case Draft:
		return "Draft"
	case Published:
		return "Published"
	case Archived:
		return "Archived"
	}
	return "Status(" + strconv.Itoa(int(s)) + ")"
}
```

`stringer` génère en plus une fonction qui ne sert qu'à **casser la compilation** si les constantes
changent de valeur :

```go
func _() {
	var x [1]struct{}
	_ = x[Draft-0]
	_ = x[Published-1]
	_ = x[Archived-2]
}
```

Tant que `Draft` vaut 0, `x[Draft-0]` est `x[0]` : valide. Si quelqu'un écrit `Draft Status = iota + 1`
sans régénérer, l'indice devient 1 et le compilateur refuse (vérifié) :

```
invalid argument: index 1 out of bounds [0:1]
```

C'est une assertion **à la compilation** : le code généré vérifie que les hypothèses sur lesquelles il a
été généré sont toujours vraies. L'outil officiel produit aussi une version plus rapide que le `switch`
(une seule chaîne et une table d'indices), mais c'est un détail.

## E5 — Le bon outil

| Besoin | Outil | Pourquoi |
|---|---|---|
| (a) cache LRU de n'importe quelle valeur | génériques | même algorithme, la valeur n'est jamais inspectée |
| (b) JSON de réponses de types variés | réflexion (`encoding/json`) | types nombreux, inconnus de la bibliothèque ; volume par réponse modeste |
| (c) `Scan` de 40 tables à fort trafic | génération | structure connue à la compilation, coût multiplié par le trafic |
| (d) validateur `validate:"min=1,max=200"` | réflexion (bibliothèque) ou génération | la réflexion est l'usage courant ; générer si le profil montre que la validation pèse |
| (e) journal qui accepte « n'importe quoi » | interface (`any` + `fmt`/`slog`) | le formatage est délégué ; `LogValuer` pour les cas particuliers (niveau 12) |
| (f) *mocks* pour 15 interfaces | génération (ou faux écrits à la main) | typés et vérifiés à la compilation |

```go
// Generate lit un fichier source et rend le code généré, ou toutes les erreurs trouvées.
func Generate(filename string, src []byte) ([]byte, error) {
	fset := token.NewFileSet()
	f, err := parser.ParseFile(fset, filename, src, parser.ParseComments)
	if err != nil {
		return nil, err
	}
	var models []model
	var errs []error
	for _, decl := range f.Decls {
		gd, ok := decl.(*ast.GenDecl)
		if !ok || gd.Tok != token.TYPE || gd.Doc == nil {
			continue
		}
		table := ""
		for _, c := range gd.Doc.List {
			if t, ok := strings.CutPrefix(c.Text, "//dbgen:table "); ok {
				table = strings.TrimSpace(t)
			}
		}
		if table == "" {
			continue
		}
		for _, spec := range gd.Specs {
			ts := spec.(*ast.TypeSpec)
			st, ok := ts.Type.(*ast.StructType)
			if !ok {
				errs = append(errs, fmt.Errorf("%s : %s n'est pas une struct", fset.Position(ts.Pos()), ts.Name))
				continue
			}
			m, err := buildModel(fset, ts.Name.Name, table, st)
			if err != nil {
				errs = append(errs, err)
				continue
			}
			models = append(models, m)
		}
	}
	if err := errors.Join(errs...); err != nil {
		return nil, err
	}
	var buf bytes.Buffer
	if err := tmpl.Execute(&buf, map[string]any{"Package": f.Name.Name, "Models": models}); err != nil {
		return nil, err
	}
	out, err := format.Source(buf.Bytes())
	if err != nil {
		return nil, fmt.Errorf("code généré invalide (bug du générateur) : %w\n%s", err, buf.Bytes())
	}
	return out, nil
}

func buildModel(fset *token.FileSet, name, table string, st *ast.StructType) (model, error) {
	m := model{Name: name, Table: table}
	seen := map[string]bool{}
	var errs []error
	for _, fl := range st.Fields.List {
		if fl.Tag == nil || len(fl.Names) != 1 || !fl.Names[0].IsExported() {
			continue
		}
		raw, _ := strconv.Unquote(fl.Tag.Value)
		tag, ok := reflect.StructTag(raw).Lookup("db")
		if !ok {
			continue
		}
		pos := fset.Position(fl.Pos())
		switch fl.Type.(type) {
		case *ast.ChanType, *ast.FuncType, *ast.MapType:
			errs = append(errs, fmt.Errorf("%s : %s.%s : type non géré", pos, name, fl.Names[0].Name))
			continue
		}
		col, opts, _ := strings.Cut(tag, ",")
		if seen[col] {
			errs = append(errs, fmt.Errorf("%s : %s : colonne %q en double", pos, name, col))
			continue
		}
		seen[col] = true
		m.Fields = append(m.Fields, field{fl.Names[0].Name, col, opts == "auto"})
	}
	if len(m.Fields) == 0 && len(errs) == 0 {
		errs = append(errs, fmt.Errorf("%s : marquée //dbgen:table mais aucun champ db", name))
	}
	return m, errors.Join(errs...)
}
```

`go test ./...` passe, `TestAgainstPostgres` compris : l'insertion par `InsertBook` + `InsertArgs` +
`AutoDest`, puis la lecture par `ColumnsBook` + `ScanBooks`, sans une ligne de réflexion à l'exécution.

Points de conception :

- **Le générateur est une bibliothèque** (`dbgen.Generate(nom, source)`) et la commande un simple
  enrobage : le test passe la source en **chaîne**, sans fichier, et compare au fichier de référence
  (*golden*) caractère par caractère.
- **Les erreurs sont positionnées** (`m.go:6:2 : A : colonne "x" en double`) grâce au `token.FileSet` :
  l'utilisateur sait où corriger son **source**.
- **Toutes les erreurs ensemble** (`errors.Join`), comme pour la configuration (leçon 2).
- La table vient d'un commentaire `//dbgen:table` (une « directive » au sens des outils Go : pas d'espace
  après `//`), lu avec `parser.ParseComments`.

## Défi — Réflexion contre génération, sur un vrai encodeur

```go
// Fichier : fastjson/write.go
// Package fastjson : un encodeur JSON minimal, en deux versions (réflexion, code généré),
// qui produit exactement la même sortie qu'encoding/json pour les types gérés.
package fastjson

import (
	"errors"
	"math"
	"strconv"
	"unicode/utf8"
)

const hex = "0123456789abcdef"

// AppendString reproduit les règles d'encoding/json : échappement HTML (<, >, &),
// U+2028 et U+2029, caractères de contrôle, UTF-8 invalide remplacé par U+FFFD.
func AppendString(b []byte, s string) []byte {
	b = append(b, '"')
	for i := 0; i < len(s); {
		c := s[i]
		if c < utf8.RuneSelf {
			switch {
			case c == '"' || c == '\\':
				b = append(b, '\\', c)
			case c == '\n':
				b = append(b, '\\', 'n')
			case c == '\r':
				b = append(b, '\\', 'r')
			case c == '\t':
				b = append(b, '\\', 't')
			case c == '\b':
				b = append(b, '\\', 'b')
			case c == '\f':
				b = append(b, '\\', 'f')
			case c < 0x20 || c == '<' || c == '>' || c == '&':
				b = append(b, '\\', 'u', '0', '0', hex[c>>4], hex[c&0xF])
			default:
				b = append(b, c)
			}
			i++
			continue
		}
		r, size := utf8.DecodeRuneInString(s[i:])
		switch {
		case r == utf8.RuneError && size == 1:
			b = append(b, `�`...)
		case r == ' ' || r == ' ':
			b = append(b, '\\', 'u', '2', '0', '2', hex[r&0xF])
		default:
			b = append(b, s[i:i+size]...)
		}
		i += size
	}
	return append(b, '"')
}

var ErrUnsupportedFloat = errors.New("json: unsupported value (NaN ou infini)")

// AppendFloat reproduit le format d'encoding/json pour un float64.
func AppendFloat(b []byte, f float64) ([]byte, error) {
	if math.IsNaN(f) || math.IsInf(f, 0) {
		return b, ErrUnsupportedFloat
	}
	abs := math.Abs(f)
	format := byte('f')
	if abs != 0 && (abs < 1e-6 || abs >= 1e21) {
		format = 'e'
	}
	b = strconv.AppendFloat(b, f, format, -1, 64)
	if format == 'e' { // 1e-07 → 1e-7
		n := len(b)
		if n >= 4 && b[n-4] == 'e' && b[n-3] == '-' && b[n-2] == '0' {
			b[n-2] = b[n-1]
			b = b[:n-1]
		}
	}
	return b, nil
}
```

```go
// Fichier : fastjson/reflect.go
package fastjson

import (
	"fmt"
	"reflect"
	"strconv"
	"strings"
	"sync"
)

type fieldEnc struct {
	key   []byte // `"nom":` déjà encodé
	index int
	enc   func([]byte, reflect.Value) ([]byte, error)
}

var plans sync.Map // reflect.Type → []fieldEnc

// Marshal : version réflexive, analyse du type mise en cache.
func Marshal(v any) ([]byte, error) {
	rv := reflect.ValueOf(v)
	if rv.Kind() != reflect.Struct {
		return nil, fmt.Errorf("fastjson : struct attendue, reçu %T", v)
	}
	return appendStruct(nil, rv)
}

func appendStruct(b []byte, v reflect.Value) ([]byte, error) {
	fields, err := planFor(v.Type())
	if err != nil {
		return nil, err
	}
	b = append(b, '{')
	for i, f := range fields {
		if i > 0 {
			b = append(b, ',')
		}
		b = append(b, f.key...)
		if b, err = f.enc(b, v.Field(f.index)); err != nil {
			return nil, err
		}
	}
	return append(b, '}'), nil
}

func planFor(t reflect.Type) ([]fieldEnc, error) {
	if p, ok := plans.Load(t); ok {
		return p.([]fieldEnc), nil
	}
	var fields []fieldEnc
	for i := range t.NumField() {
		sf := t.Field(i)
		if !sf.IsExported() {
			continue
		}
		name := sf.Name
		if tag, ok := sf.Tag.Lookup("json"); ok {
			n, _, _ := strings.Cut(tag, ",")
			if n == "-" {
				continue
			}
			if n != "" {
				name = n
			}
		}
		enc, err := encoderFor(sf.Type)
		if err != nil {
			return nil, fmt.Errorf("champ %s : %w", sf.Name, err)
		}
		key := append(AppendString(nil, name), ':')
		fields = append(fields, fieldEnc{key, i, enc})
	}
	p, _ := plans.LoadOrStore(t, fields)
	return p.([]fieldEnc), nil
}

func encoderFor(t reflect.Type) (func([]byte, reflect.Value) ([]byte, error), error) {
	switch t.Kind() {
	case reflect.String:
		return func(b []byte, v reflect.Value) ([]byte, error) { return AppendString(b, v.String()), nil }, nil
	case reflect.Int, reflect.Int64, reflect.Int32:
		return func(b []byte, v reflect.Value) ([]byte, error) { return strconv.AppendInt(b, v.Int(), 10), nil }, nil
	case reflect.Float64:
		return func(b []byte, v reflect.Value) ([]byte, error) { return AppendFloat(b, v.Float()) }, nil
	case reflect.Bool:
		return func(b []byte, v reflect.Value) ([]byte, error) { return strconv.AppendBool(b, v.Bool()), nil }, nil
	case reflect.Slice:
		elem, err := encoderFor(t.Elem())
		if err != nil {
			return nil, err
		}
		return func(b []byte, v reflect.Value) ([]byte, error) {
			if v.IsNil() {
				return append(b, "null"...), nil
			}
			b = append(b, '[')
			var err error
			for i := range v.Len() {
				if i > 0 {
					b = append(b, ',')
				}
				if b, err = elem(b, v.Index(i)); err != nil {
					return nil, err
				}
			}
			return append(b, ']'), nil
		}, nil
	}
	return nil, fmt.Errorf("type %s non géré", t)
}
```

`book_json.go` est ici écrit **comme le produirait** un générateur bâti sur le modèle de `dbgen` (un
fragment de modèle par sorte de champ) ; écrire ce générateur est la suite naturelle de l'exercice.

**Équivalence.** Les trois encodeurs produisent exactement la même sortie qu'`encoding/json` sur la table
(échappement HTML `<>&`, U+2028/U+2029, caractères de contrôle, UTF-8 invalide → `�`, flottants
`1e+21`, `1e-7`, `-0`, plus grand et plus petit `float64`), et le fuzzing ne trouve aucun écart en
≈ 240 000 exécutions. Reproduire **exactement** un format existant demande de connaître ses règles une
à une : le fuzzing contre l'implémentation de référence est la seule façon raisonnable de s'en assurer.

**Mesures** (10 000 objets, `-benchmem`) :

| Encodeur | Temps | Mémoire | Allocations |
|---|---|---|---|
| `encoding/json` | 11,3 ms | 2,7 Mo | 30 000 |
| réflexion maison (avec cache) | 7,3 ms | 3,3 Mo | 60 000 |
| généré, tampon réutilisé | 2,1 ms | 0 | 0 |

Lecture honnête :

- la réflexion maison est plus rapide qu'`encoding/json` parce qu'elle fait **beaucoup moins** : pas
  d'interfaces `Marshaler`, pas d'`omitempty`, pas de pointeurs ni de maps, pas de vérification de
  validité. Elle alloue **plus**, car chaque appel part d'un tampon vide qui grandit ;
- le code généré combine deux gains qu'il faut distinguer : pas de réflexion, **et** un tampon réutilisé
  d'un objet à l'autre (`buf[:0]`). Avec un tampon neuf par objet, il allouerait comme les autres ;
- ×5 contre `encoding/json` sur l'encodage seul. Dans un service, l'encodage n'est qu'une partie du
  temps de réponse (réseau, base) : le gain réel se mesure sur le service entier (niveau 11).

**Quand générer son JSON** : un service dont le profil (pprof, niveau 11) montre que l'encodage JSON
domine — API à très fort débit, réponses volumineuses. Coûts : un générateur à maintenir, chaque règle
du format à reproduire (et à re-vérifier à chaque version de Go), un risque de divergence subtile. Avant
d'en arriver là, essayer `encoding/json/v2` (N4 L6), plus rapide que v1, et réutiliser les tampons.
